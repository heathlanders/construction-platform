## Best starting sources
Group baseline: 1926 Subpart Q; UFGS 03/04; NRMCA CIP, ACI free docs, NCMA TEK, BIA Tech Notes; 1926 Subparts D (silica/dust), X (ladders); UFGS 09/12; trade assoc (NWFA, CRI, TCNA-ref, AWCI, CISCA, AWI); 1926 Subpart P (excavation), O (equipment); UFGS Div 31–33; WisDOT std spec + avg unit prices; 1926 Subparts M (fall), R (steel), CC (cranes); UFGS 05/06; AWC, AISC free specs

- **`structural_steel`** — AISC 303 Code of Standard Practice (free); 1926 Subpart R; UFGS 05 12 00
- **`metal_decking`** — SDI (Steel Deck Institute) manuals (ref); 1926.754–760
- **`misc_metals`** — NAAMM Metal Stairs/Rails (ref); UFGS 05 50 13; 1926 Subpart X
- **`welding`** — AWS D1.1 (ref); 1926 Subpart J (welding/cutting, public)
- **`precast_erection`** — PCI erection manuals (ref); 1926.704
- **`deep_foundations`** — FHWA drilled shaft (NHI-18-024) + driven pile manuals; 1926.603 pile driving
- **`shoring_underpinning`** — 1926 Subpart P; FHWA soil nail/micropile manuals
- **`metal_stud_framing`** — SFIA tech notes; AISI S240 (ref); UFGS 09 22 16
