## 1. Schema + registry — `api/src/lib/trades/packs/`
- `schema.ts` — zod schema exactly per spec §3. Export `TradePackSchema`, `TradePack`, `definePack()`
  (identity fn with type inference), `I18nText`, `Prov`, `Sourced`, `Match`, `Recipe`, `StepTpl`,
  `Hazard`, `PackAssembly`, `QtyRule`. `InspectionType` = union of every `inspection_type` across the 4
  `*-codes/inspection-sequences.ts` (derive the string list at module load; zod `refine`, not a TS enum
  copy). `EquipmentType` from `task-buildout/equipment-vocab.ts`. `PhaseType`/`BuildingType` from
  `blueprint-templates/types.ts` / `jurisdictions/types.ts`.
- `sources.ts` — `SOURCES` const (`satisfies Record<string, SourceDef>`), `SourceId = keyof typeof SOURCES`,
  `license` ∈ `public_domain|gov_open|manufacturer_public|association_public|platform_estimate|proprietary_ref_only`.
  Seed with the shared Tier-1 sources used by most packs: eCFR 1926 subparts C, D, E, K, L, M, N, O, P,
  Q, R, T, V, X, Z (ids `ecfr-1926-<subpart>`), UFGS index (`ufgs`), DOE BASC (`doe-basc`), BLS OEWS
  (`bls-oews`), SAM.gov wage determinations (`sam-wd`), ICC public access (`icc-pa`, proprietary_ref_only),
  NFPA free access (`nfpa-fa`, proprietary_ref_only), and `platform-baseline` with its own license
  `platform_estimate` (our expert baselines — guards treat it as non-proprietary but require
  `confidence: 'estimate'` on any value citing it).
- `runtime.ts` (pure):
  - `packFor(tradeKey)` → pack via `normalizeTradeKey` then `PACKS`; `null` for stubs with no recipes.
  - `matchStep(match, ctx: BuildContext)` — phase ∈, `new RegExp(title_re,'i')` on title+description,
    `facts_any` against `facts.components` + truthy `facts.flags[k]`, `building_types` ∈.
  - `renderTemplate(s, ctx)` — placeholders `${ct}`, `${ed}`, `${bt}`, `${facts.panel_amps}`,
    `${facts.window_count}`, `${facts.door_count}`, `${facts.room_count}`, `${facts.area_sf}`; unknown →
    throw in tests (guard), `—` at runtime.
  - `renderPackSteps(pack, ctx): WorkStep[]` — highest-priority matching recipe; steps' `safety` =
    `resolveHazards(safety_ids)` short strings (`hazard — first control`), `qa_check` = joined QA items,
    `code_refs` → `{code_type: ctx.resolved.code_type, section, note}`.
  - `packEquipment(pack, ctx, stepTitle)`, `evalQty(rule, facts)`, `packComponents()` (flattened, sorted
    by key for determinism), `packKnowledge(key, lang)` (endpoint payload).
- `index.ts` — **generated** by `pack:barrel` (imports every `*.ts` except schema/sources/runtime/index).
