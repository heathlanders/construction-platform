- heavy_civil: `permit_trade` null → **no** `gating_inspection_type`; put DOT/owner hold points in `inspection_checklists` keyed by a descriptive id (e.g. `dot_density_test`). `est_bucket: 'general'`, codes `HC-…`. Costs from DOT bid tabs (`derived`).
- Trades with a hand recipe: the pack must **complement** it (QA, hazards, inspection checklists, glossary, assemblies). Only set `supersedes_hand: true` if the pack recipe is strictly better, and update task-buildout snapshots in the same PR.
- Safety ES = `pending_human_translation`; non-safety ES written now.
- New equipment types / inspection types → REVIEW_QUEUE (`vocab`), not invented in packs.
