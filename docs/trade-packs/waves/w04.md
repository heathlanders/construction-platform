## Best starting sources
Group baseline: 1926 Subpart M (fall) + roofing; UFGS 07/08; DOE BASC; NRCA/SPRI/FGIA/EIMA; 1926 Subpart P (excavation), O (equipment); UFGS Div 31–33; WisDOT std spec + avg unit prices; 1926 Subparts M (fall), R (steel), CC (cranes); UFGS 05/06; AWC, AISC free specs

- **`decks`** — AWC DCA 6 (prescriptive deck guide); IRC R507 (ref); Simpson deck connection guide; Trex/TimberTech install
- **`patio_covers_awnings`** — IRC App. H patio covers (ref); manufacturer (Alumawood, Four Seasons) install guides; FEMA wind
- **`hardscape_pavers`** — ICPI tech specs + NCMA TEK (SRW/pavers); UFGS 32 14 13; Belgard/Unilock install guides
- **`concrete_flatwork`** — ACI 302/330 (ref); NRMCA CIP 20/30; UFGS 32 13 13; existing intake module data (lib/intake/trades/concrete_flatwork.ts)
- **`fencing`** — UFGS 32 31 13; AFA (American Fence Assoc) resources; pool barrier IRC App. G / ISPSC (ref)
- **`landscaping`** — USDA NRCS practice standards; ANSI A300 (ref); UFGS 32 90
- **`irrigation`** — IA (Irrigation Assoc) BMPs; backflow per plumbing code (ref); UFGS 32 84
- **`gutters`** — SMACNA Architectural Sheet Metal Manual (ref); mfr install; IRC R801.3 (ref)
