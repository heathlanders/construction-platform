## Best starting sources
Group baseline: 1926 Subpart Q; UFGS 03/04; NRMCA CIP, ACI free docs, NCMA TEK, BIA Tech Notes; 1926 Subparts D (silica/dust), X (ladders); UFGS 09/12; trade assoc (NWFA, CRI, TCNA-ref, AWCI, CISCA, AWI); 1926 subparts per hazard; UFGS 10–14/41; trade associations listed per trade

- **`remodeling`** — EPA RRP 40 CFR 745 (lead); IEBC (ref); NAHB remodelers resources; HUD rehab guides
- **`foundation_repair`** — IRC R401–R403 (ref); manufacturer helical/push pier guides (Chance, Ram Jack); FHWA micropile manual
- **`concrete_repair_lifting`** — ICRI technical guidelines (ref); polyurethane foam mfr guides; NRMCA CIP
- **`restoration`** — IICRC S500/S520 (ref-only); EPA mold remediation guide (public); FEMA flood recovery guides
- **`abatement`** — 40 CFR 61 Subpart M (NESHAP), 1926.1101 asbestos, 1926.62 lead, EPA mold guide
- **`radon_mitigation`** — EPA RRNC / radon guides (public); AARST (ref-only); IRC App. F (ref)
- **`chimney`** — CSIA + HPBA guidance; NFPA 211 (ref); IRC R1001–R1003 (ref)
- **`closets_storage`** — mfr install guides (ClosetMaid, Elfa); 1926 Subpart X ladders
