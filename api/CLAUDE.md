## Blueprint extraction paths (text + OCR — no AI)
- `POST /v1/blueprints/analyze` auto-selects: no `document_id` → template; vector PDF → `text_extraction`; **scanned PDF (`is_vector=false`) → `ocr_extraction`** via `api/src/lib/blueprint-pdf/ocr.ts` (`ocrPdfToText`: `mupdf` rasterize → `tesseract.js` OCR; both pure-WASM, **no system deps / no AI / no network** — `eng.traineddata` vendored at `api/assets/tessdata/`, override path with `TESSDATA_PATH`). Worker (`runTextExtractionPath`) tries OCR on the scanned branch; falls to `template_scanned_fallback` only if `ocrYieldChars < 200` or OCR throws. `import_metadata.source` records the path.
- **High-DPI OCR for accurate data:** full page is OCR'd at `OCR_PAGE_DPI` (default 300) via **adaptive tiling** (`ocrPageTiled` — splits the sheet into clipped DrawDevice tiles capped at `OCR_TILE_MAX_PX` px/side, 4% overlap, OCR each, concat; small sheets = 1 tile). A **second pass** renders the bottom-right **title-block corner** at 450dpi/PSM-6 (`renderTitleBlockPng`) → `ExtractedPage.title_block_text`, so tiny legend glyphs read correctly (e.g. ZIP `53527` vs the full-page misread `53521`). Title block (drafter/builder/build location) extracted in `blueprint-pdf/title-block.ts` (`extractTitleBlock` → `mergeTitleBlock` prefers the crop → `voteTitleBlock` cross-sheet) → `import_metadata.{title_block, builder_profile, location_suggestion}`. `BUILDER_PROFILES` (Example Drafting / Example Properties = Dane County WI residential) give authoritative county + processing hints; `repairOcrZip` (jurisdictions) snaps OCR digit-misreads to a seeded ZIP. Location is a SUGGESTION — never overwrites the project. Tune crop via `TB_FRAC_X/Y`.
- OCR text is noisy → `parse-sheets.ts` has OCR-grade detectors that DON'T need schedule tables: bare room labels (`BARE_ROOM_PATTERNS`), `COMPONENT_PATTERNS` (trusses/TJI/LVL/footings/anchor-bolts/R-values/siding + post-frame columns/girts/purlins/metal panels), WI `SPS` code refs (accepts OCR-mangled `5PS`). `build-tasks.ts` `comp(...)` branches turn components → augment tasks (`sort_order>=2000`), + a residential-room summary task. All additive + building-type-agnostic (vector fixtures unaffected).
- Building types incl. `pole_barn` (post-frame; `blueprint-templates/pole-barn.ts`). To add a type: see `.claude/skills/blueprint-intelligence/SKILL.md`. Tests: `api/src/test/blueprint-ocr.test.ts` (+ vendored `madison-lot25-ocr.txt`). Real Madison WI scans → 62 tasks (47 base + 15 augments). See memory `madison_blueprint_ocr`.

## Schedule dependencies + Project Overview (Session 33; migration 0018)
